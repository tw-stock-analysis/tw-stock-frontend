# 除權息、交易日曆與個股風險提示

由「研究工具」的「除權息與日曆」「風險公告」進入。皆為公開查詢，不寫入資料庫或 localStorage，也沒有行情快取、自動重試或輪詢。

## 日曆

`/research/calendar` 支援事件類型（全部／除權息／開休市公告）、代碼／名稱／事項、起迄日及分頁。條件保留在網址，送出時重設頁碼，輸入時不請求。快捷「未來 30 天（含今天）」以臺北日期起算；「全部來源日期」移除日期區間，保留其他條件。只篩選來源已提供的事件，不推測未列出的日期是開市或休市。

日期同時顯示 ISO 格式與官方原值；說明摘要為純文字，所有官方欄位可展開查看，HTML 不會執行。日期不明資料另列數量，不以取得時間補日期。部分來源失敗時保留本輪成功事件、顯示不完整訊息與各來源狀態，不沿用舊結果。

「下載完整日期事件 ICS」忽略分頁，重新取得所選來源的完整篩選結果。來源必須全部成功，否則顯示下載失敗，不假裝產生完整日曆。沒有日期的事件略過並回報筆數。檔案可匯入 Google、Apple 或 Outlook 等日曆工具；這是單次匯入，不會自動同步公告異動。離開或更新時中止尚未完成的下載。

## 官方風險公告

`/research/risks` 可輸入精確證券代碼，或留空查看全部；也可選擇注意、處置或暫停交易其中一種來源。後端依序請求，每份來源獨立標示成功、失敗、公告筆數與取得時間。部分成功顯示不完整狀態，全失敗清除結果。成功空資料與官方的零筆標記也會正確顯示，未列出不代表無其他風險或必然可交易。

公告卡片保留官方公布日期、處置期間、措施、暫停與恢復交易日期時間；完整內容可展開。不根據這些可能包含歷史公告的快照推斷現在生效狀態，也不計算風險分數。

個股 `/stocks/:code` 頁新增「取得此股風險公告」按鈕，使用者點選後才取得三份來源，不增加原本成交／估值／資券的自動請求。換股、更新或離開頁面會中止並清除查詢結果；可從連結進入該股完整公告頁。
