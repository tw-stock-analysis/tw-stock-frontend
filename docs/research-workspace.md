# 多市場與個人研究工作區

新增四組流程，提醒通知依使用者決定先跳過。

| 入口 | 功能 |
| --- | --- |
| `/instruments` | 上市、上櫃、興櫃、下市櫃來源參考搜尋、分頁；歷史市場／名稱與日期參考 |
| `/instruments/:market/:code` | 身分參考、指定區間收盤價，連至多市場歷史／進階研究 |
| `/research/factors` | 1–10 檔候選的營收年增、毛利率、營益率、負債比、外資／投信連買門檻及排序 |
| `/workspace` | 私人筆記、篩選條件、圖表偏好、2–4 檔命名比較與手動帳本 |
| `/portfolio` | 買賣、費稅、股利收入與股數調整；已實現、未實現、成本及總損益 |
| `/research/backtest` | 單一證券買入持有或均線回測、成本／稅／滑價、交易單位、資產曲線及委託明細 |

行情與來源名錄逐次重新查詢；不自動重試、不背景輪詢、不使用 localStorage，也不保存行情、篩選結果或回測結果。後端只將經型別驗證的使用者輸入存入 `app.workspace_items`，須先執行 migration `0005_workspace`。

工作區需先登入，透過 `store.privateRequest` 讀寫本人文件；登出或 Session 失效移除私人內容。儲存使用目前版本，版本衝突顯示 409 並保留本機編輯，使用者可重新載入；查詢按鈕使用**已儲存版本**，修改後須先儲存。同類型同名文件不能重複，最多 100 份。私人 POST／PUT／DELETE 都送同源 Cookie、JSON 及 CSRF header。

圖表偏好包含 MA／布林、RSI／MACD 與天數，開啟歷史頁時經 URL 套用；命名比較逐檔重新取得最近 30 天的最後可用收盤價並標示日期。篩選文件可重新執行。筆記可開啟證券研究。

名錄只有來源參考，日期不是上市日，沒有永久證券 ID 或完整的歷史市場別；歷史名稱衝突不會自動混合行情。名錄含歷史紀錄，不保證每檔仍交易；來源沒提供當期行情時明示空資料。興櫃開盤欄可能為前日均價等來源參考，回測不接受興櫃。

候選篩選不是全市場掃描；空白門檻不查該項。缺值、錯誤與未完成候選不列為符合，保留各項來源期間；法人連買依來源可用日期，非保證連續交易日。財報期間不等於公告時間，可能重編，不作歷史時點因子回測。

帳本採移動平均成本。買進成本含費稅；賣出按股數攤分成本後扣費稅；現金股利由使用者登錄，分割／配股調整股數但維持總成本。相同日期依清單順序，不允許超賣。複雜返還資本減資須自行調整原帳本。缺行情時市值、未實現及總損益留空。估值非即時價，使用最近可用收盤價；查詢中帳本被修改時要求重載。

回測以前一有效日收盤訊號、次一有效日開盤模擬成交，暖機不足不交易；原始價格不含股利再投資，分割／減資等事件須改用具權限的還原模式。使用者設定費率、最低費用、稅、滑價與 1／1,000 股單位，期末不強制賣出。未模擬流動性、漲跌停排隊、完整企業行動會計或跨股資產配置。還原價格為來源調整單位，不是實際歷史成交價。

詳細 API、上限、計算與資料限制見 [後端契約](https://github.com/tw-stock-analysis/tw-stock-backend/blob/feat/market-research-tools/docs/research-workspace.md)。瀏覽器驗證只保存狀態摘要，無行情明細。
