# 研究工具

由主要導覽「研究工具」進入，也可從首頁及個股搜尋頁開啟選股篩選器。五頁皆為公開功能，不需登入，且不使用資料庫、localStorage、行情快取或自動輪詢。

| 路由 | 使用方式 |
| --- | --- |
| `/research/screener` | 輸入代碼／名稱、股價區間、漲跌幅區間、最低成交股數，選擇排序及每頁筆數，再按「套用篩選」 |
| `/research/compare?codes=0050,2330` | 輸入 2～4 個不同代碼，或從篩選結果勾選後按「比較所選證券」 |
| `/research/overview` | 同一次快照最新有效交易日的漲跌分布、漲幅／跌幅／成交量前 10 名 |
| `/research/calendar` | 除權息、開休市事項日期篩選、未來 30 天及完整 ICS 下載 |
| `/research/risks?code=0050` | 注意、處置、暫停交易公告與各來源狀態；個股頁亦可按次取得 |

條件、排序、頁碼與比較代碼放在 URL，可分享與重新整理。輸入時不自動請求，送出條件、分頁、手動重新取得時才重新查詢；變更條件會回第一頁。比較代碼可用逗號、全形逗號或空白分隔，重複或不合法的代碼不呼叫後端。

篩選器每頁最多勾選 4 檔；換頁、更新或重新查詢後清除勾選。按「匯出全部結果 CSV」會以目前已套用條件重新取得完整結果，並非只匯出當頁；匯出時可以與畫面先前取得的資料不同。下載失敗顯示訊息，離開頁面或重新取得資料時中止下載請求。CSV 以單引號保留證券代碼前導零，亦處理可能被試算表執行的公式字串。

各頁清楚標示官方日成交快照、資料日期、臺北取得時間與來源。成交股數以股為單位。漲跌幅由後端 Decimal 推算並四捨五入至小數 4 位，前端只顯示，不以浮點數重新篩選或計算。數值缺失顯示 —，不補零；漲跌有正負符號及顏色。

股票比較只向後端送出一個請求，由後端依序取得成交與估值兩份來源。估值缺失、未知代碼、估值來源失敗分別呈現；估值錯誤時仍顯示本輪成功取得的成交。重新取得時隱藏原資料，失敗不沿用舊數值。市場總覽排除其他日期與日期不明資料，顯示統計範圍含 ETF 等上市證券，並連結既有官方市場指數頁。

使用 `services/research.ts` 的 Router loaders 與 `cache: 'no-store'`，沿用同源 `/api/v1` 及導覽取消訊號。API 契約、條件及計算規則見後端 [公開研究工具](https://github.com/tw-stock-analysis/tw-stock-backend/blob/feat/market-research-tools/docs/research-tools.md)。

日曆及官方公告使用 `services/notices.ts`，日期、完整下載與來源不完整狀態說明見 [日曆與風險公告](calendar-and-risks.md)。

`tests/research-tools.test.tsx` 覆蓋 URL 還原、明確送出條件、分頁、勾選比較、代碼驗證、不同日期／部分來源失敗、清除舊結果及 CSV 成功／失敗。2026-10-23 另以真實 TWSE 經 Vite → FastAPI 完成桌面與手機瀏覽器驗證，三頁無 JavaScript 錯誤或整頁橫向溢出，下載完整 CSV（當次 1,368 筆）且保留代碼前導零；此輪不連線資料庫。
