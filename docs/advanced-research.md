# 永久證券身分與進階研究

新增三個可由研究導覽進入的流程：

| 入口 | 功能 |
| --- | --- |
| `/research/security-identity` | 依市場、代碼與指定日期查詢永久 UUID；包含已終止紀錄 |
| `/research/security-identity/:securityId` | 穩定網址、有效掛牌區間、名稱／ISIN 別名與起訖來源證據 |
| `/research/market-screen` | 全市場單期營收與財報門檻、排序、分頁、完整候選分母及缺值統計 |
| `/research/portfolio-backtest` | 2–20 檔固定權重、動能或低波動因子，月／季再平衡與成本損益 |

提醒通知繼續跳過。沒有背景查詢、行情快取、行情寫入或自動重試；新頁面延遲載入，查詢中隱藏舊結果，可取消並忽略已取消回應。

證券身分來自後端永久登錄表，需部署 migration `0006_security_identity` 並由操作人員初始化官方或已審核證據。區間含生效日、不含終止生效日；缺口顯示未知，衝突顯示無法確認，歷史連結保留使用者選擇的日期。UUID 不依代碼改變，統編只識別發行人。官方初始匯入主要涵蓋可證實的 TWSE 區間；上櫃／興櫃完整歷史、ISIN 與歷史名稱須補有日期的證據，不推定已取得全市場永久身分史。

全市場掃描使用 FinMind 整份快照，需相應付費權限；權限不足清楚顯示，不偷偷逐股替代。營收月份與財報季末由使用者指定，財報期間不是公告時間；缺值、未符合及身分錯誤分開計數，分頁重新取得來源。這不是歷史時點的完整存活者偏誤修正選股。

回測預設驗證歷史證券身分與必要因子暖機。明確選擇未驗證研究模式才可放寬，結果會保留提醒。固定權重合計不超過 1，餘額留現金；因子模式移除手動權重，由排序後 top_n 等權配置。前日收盤產生訊號、當日開盤只作成交與股數換算，先賣後買，費用不足時按比例縮減買進，不借款。共同交易日缺價、停牌或起訖不完整會停止，不用舊價回填；來源還原模式需要相應權限。

費率為小數，股數單位為 1 或 1,000 股；介面展示資產曲線、訊號／成交日、權重／分數、委託、報酬、回撤與雙邊成交金額／初始資金的周轉比。原始模式不含股利再投資；未模擬漲跌停排隊、流動性或券商逐筆進位。因子目前為價格動能與低波動，不冒充缺少公告日的財報因子回測。

詳細 API、匯入方式與資料缺口見 [後端契約](https://github.com/tw-stock-analysis/tw-stock-backend/blob/feat/market-research-tools/docs/advanced-research-scope.md)。驗證摘要只保存狀態與數量，不含行情明細。
